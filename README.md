## Publicar en GitHub Pages

1. Sube este repositorio a GitHub.
2. En el repositorio: **Settings → Pages**.
3. **Source:** Deploy from a branch.
4. **Branch:** `main` (o `master`) · **Folder:** `/ (root)`.
5. Guarda. En unos minutos el sitio quedará en  
   `https://<tu-usuario>.github.io/<nombre-del-repo>/`

El archivo `index.html` en la raíz es la página principal. Los PDFs se abren con rutas relativas desde las mismas carpetas.

## Vista local

Abre `index.html` en el navegador o usa un servidor local:

```bash
npx --yes serve .
```

## Estructura

- `index.html` — contenido y bibliografía
- `styles.css` — estilos
- `script.js` — navegación suave
- Carpetas `Practica*` / `EnsayoUnidad1` / `Cuestionario1.3` — PDFs
